# Three.js 효과 디렉토리

이 디렉토리는 Three.js 효과 모듈의 소스 코드를 포함합니다.

## 📁 구조

- `base/` - 기본 효과 클래스
- `examples/` - 예제 효과 구현
- `types.ts` - 타입 정의
- `loader.ts` - 효과 로더
- `loader.test.ts` - 로더 테스트
